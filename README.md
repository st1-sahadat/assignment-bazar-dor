
## Project name :
 assignment-bazar-dor

A modern online marketplace platform built for buying and selling products in a smooth, secure, and user-friendly way. This project focuses on creating a digital bazaar experience where users can discover products, list their own items, and manage transactions efficiently.

## Project Overview / Short description
BazarDor brings the concept of a local market to the digital world, making it easy for people to buy and sell products online. Whether users are searching for daily essentials or unique items, the platform offers a clean interface and reliable experience.

## Technologies Used:
- Next.js
- TypeScript
- MongoDB
- Tailwind CSS
- Better auth Authentication Services

## 5 Key Features
1. User-friendly product browsing with modern categories and search filters
2. Secure buyer and seller account system with authentication and authorization
3. Product listing and management dashboard for sellers
4. Real-time order and transaction tracking experience
5. Responsive design optimized for desktop, tablet, and mobile devices
